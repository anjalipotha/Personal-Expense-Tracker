# 💰 Personal Expense Tracker

A simple and responsive **Personal Expense Tracker** built using **HTML, CSS, and JavaScript**.
The application helps users record their income and expenses and keeps track of their overall balance.

## 📌 About the Project

Managing daily expenses manually can be difficult. This project provides a simple web-based solution to record transactions and monitor personal finances.

Users can add income or expenses, select categories, view their transaction history, and automatically calculate their total income, total expenses, and remaining balance.

## ✨ Features

* ➕ Add income and expense transactions
* 🏷️ Select expense categories
* 💰 Automatically calculate total income
* 💸 Automatically calculate total expenses
* 📊 Display current balance
* 📋 View transaction history
* 🗑️ Delete transactions
* 💾 Store data using Browser Local Storage
* 🔄 Data remains available after page refresh
* 📱 Responsive design for different screen sizes
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript** – Application logic and dynamic functionality
* **Local Storage** – Storing transactions in the browser

1. Enter the transaction description.
2. Enter the amount.
3. Select whether it is an **Income** or **Expense**.
4. Select the appropriate category.
5. Click the **Add Transaction** button.
6. The transaction is displayed in the transaction list.
7. The dashboard automatically updates:

   * Total Income
   * Total Expenses
   * Current Balance
8. Transactions are stored in **Local Storage**, allowing them to remain after refreshing the browser.

## 🖥️ User Interface

The application contains:

### Dashboard

Displays the user's:

* Total Income
* Total Expenses
* Available Balance

### Add Transaction Form

Allows users to enter:

* Transaction description
* Amount
* Transaction type
* Category

### Transaction History

Displays all added transactions and provides an option to delete them.
